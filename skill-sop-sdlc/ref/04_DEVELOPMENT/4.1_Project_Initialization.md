# 4.1 Project Initialization

## วัตถุประสงค์

ตั้งค่าโปรเจกต์ให้พร้อมพัฒนา: สร้าง repository, ติดตั้ง dependencies, ตั้งค่า environment

---

## 1. สร้าง Git Repository

```bash
# สร้างโฟลเดอร์สำหรับโปรเจกต์
mkdir DM-S-09-project-name
cd DM-S-09-project-name

# ตั้งค่า Git Repository แบบ Local
git init

# สร้าง develop branch
git checkout -b develop
```

**Branch Strategy:**

| Branch | หน้าที่ |
|--------|---------|
| `main` | Production (ห้ามแก้ไขโค้ดตรงโดยไม่ผ่านการทดสอบ) |
| `develop` | Development |
| `feature/*` | ฟีเจอร์ใหม่ |
| `bugfix/*` | แก้ bug |
| `hotfix/*` | แก้ไขเร่งด่วน |

## 3. Frontend Setup (Vite + React + TypeScript + Tailwind)

```bash
# สร้างโปรเจกต์ด้วย Vite
npm create vite@latest frontend -- --template react-ts
cd frontend
```

> 📦 **เลือก dependency ตามชนิดแอป:** ดู [4.1.1 Dependencies Checklist](4.1.1_Dependencies_Checklist.md) สำหรับรายการแบบแบ่ง Tier (Base / Dashboard / Forms / Mobile / ฯลฯ)

### ติดตั้ง Dependencies

```bash
# Core
npm install react-router-dom zustand axios
npm install react-hook-form zod @hookform/resolvers
npm install clsx react-icons date-fns

# Tailwind CSS
npm install -D tailwindcss @tailwindcss/vite

# Dev tools
npm install -D @types/node
npm install -D eslint @typescript-eslint/parser @typescript-eslint/eslint-plugin
npm install -D eslint-plugin-react eslint-plugin-react-hooks eslint-config-prettier
npm install -D prettier
```

### ตั้งค่า Tailwind CSS

**`vite.config.ts`:**
```typescript
import tailwindcss from '@tailwindcss/vite'
import react from '@vitejs/plugin-react'
import { defineConfig } from 'vite'

export default defineConfig({
  plugins: [
    tailwindcss(),
    react(),
  ],
})
```

**`src/index.css`:**
```css
@import "tailwindcss";
```

### เพิ่ม Scripts ใน `package.json`

```json
{
  "scripts": {
    "dev": "vite",
    "build": "tsc -b && vite build",
    "preview": "vite preview",
    "lint": "eslint . --ext ts,tsx --report-unused-disable-directives --max-warnings 0",
    "lint:fix": "eslint . --ext ts,tsx --fix",
    "format": "prettier --write \"src/**/*.{ts,tsx,css}\""
  }
}
```

### ทดสอบ

```bash
npm run dev
# เปิด http://localhost:5173
```

## 4. Backend Setup (Node.js + TypeScript + Express)

```bash
cd ../backend
npm init -y
```

> 📦 **เลือก dependency ตามชนิดแอป:** ดู [4.1.1 Dependencies Checklist](4.1.1_Dependencies_Checklist.md) สำหรับรายการแบบแบ่ง Tier (Base+Security / Auth / DB / Upload / S3 / Cron / ฯลฯ) และ Security Checklist ก่อนขึ้น production

### ติดตั้ง Dependencies

```bash
# Core
npm install express cors dotenv
npm install pg
npm install jsonwebtoken bcrypt zod

# Dev tools
npm install -D typescript ts-node nodemon
npm install -D @types/node @types/express @types/cors @types/jsonwebtoken @types/bcrypt @types/pg
npm install -D eslint @typescript-eslint/parser @typescript-eslint/eslint-plugin
npm install -D eslint-config-prettier prettier
```

> ⚠️ **ก่อน deploy:** ย้าย `typescript` + `tsx` + `@types/*` ที่ build ต้องใช้ ไปไว้ใน `dependencies` (ไม่ใช่ `-D`) — Railway ตั้ง `NODE_ENV=production` แล้วข้าม `devDependencies` ทำให้ `tsc` build ไม่ผ่าน. ดูรายการแบบแบ่งชัดที่ [4.1.1 Dependencies Checklist](4.1.1_Dependencies_Checklist.md#️-tier-0--base--security-ทุก-api-ต้องมี)

### ตั้งค่า TypeScript

```bash
npx tsc --init
```

**แก้ไข `tsconfig.json`:**
```json
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "commonjs",
    "lib": ["ES2022", "DOM"],
    "outDir": "./dist",
    "rootDir": "./src",
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true,
    "forceConsistentCasingInFileNames": true,
    "resolveJsonModule": true,
    "noUnusedLocals": true,
    "noUnusedParameters": true
  },
  "include": ["src/**/*"],
  "exclude": ["node_modules", "dist"]
}
```

> ⚠️ **skipLibCheck: true** (ด้านบน) ต้องคงไว้ และ **ตรวจสอบบน local branch** ว่าบรรทัดนี้ไม่หล่นหาย (ดู [5.2 §2](../05_DEPLOY/5.2_Pre_Deploy_Checklist.md)).

### สร้าง Entry Point

**`src/server.ts`:**
```typescript
import express from 'express';
import cors from 'cors';
import dotenv from 'dotenv';

dotenv.config();

const app = express();
const PORT = process.env.PORT || 5000;

app.use(cors({
  origin: process.env.ALLOWED_ORIGINS?.split(',') || 'http://localhost:5173',
  credentials: true,
}));
app.use(express.json());

app.get('/health', (req, res) => {
  res.json({ status: 'OK' });
});

app.listen(PORT, () => {
  console.log(`Server running on http://localhost:${PORT}`);
});
```

### เพิ่ม Scripts ใน `package.json`

```json
{
  "scripts": {
    "dev": "nodemon src/server.ts",
    "build": "tsc",
    "start": "node dist/server.js",
    "lint": "eslint . --ext .ts",
    "lint:fix": "eslint . --ext .ts --fix",
    "format": "prettier --write \"src/**/*.ts\""
  },
  "engines": { "node": ">=22" }
}
```

> ⚠️ **`engines.node` = Node 22+** : PostgreSQL SDK ใช้ native `WebSocket` ที่ Node 20 ไม่มี → `createClient()` crash ตอน boot → health check ไม่เคยผ่าน. nixpacks อ่าน major version จาก `engines` (ดู `nixpacks.toml` ใน [5.2 §3](../05_DEPLOY/5.2_Pre_Deploy_Checklist.md)).

### Lazy PostgreSQL Client Init

สร้าง client **ตอนเรียกครั้งแรก** ไม่ใช่ตอน import:

**`src/config/database.ts`:**
```typescript
import { Pool } from 'pg';

let pool: Pool | null = null;

export function getDatabase(): Pool {
  if (!pool) {
    pool = new Pool({
      connectionString: process.env.DATABASE_URL,
    });
  }
  return pool;
}
```

> ถ้า `new Pool()` ถูกเรียกตอน import (top-level) และ runtime ขาด env หรือ database ขัดข้อง จะ throw **ก่อน** `app.listen()` → server ไม่ขึ้น → health check timeout.

### ทดสอบ

```bash
npm run dev
curl http://localhost:5000/health
```

## 5. Environment Variables

**สร้าง `.env.example` ที่ root:**

```bash
# Frontend
VITE_API_URL=http://localhost:5000

# Backend
PORT=5000
NODE_ENV=development
DATABASE_URL=postgresql://user:password@localhost:5432/dbname
JWT_SECRET=your_secret_key
JWT_EXPIRES_IN=7d
ALLOWED_ORIGINS=http://localhost:5173
```

> **สำคัญ:** Copy `.env.example` เป็น `.env` แล้วใส่ค่าจริง — ห้าม commit `.env`

## 6. Git Hooks (Husky)

```bash
cd ..  # กลับ root
npm init -y
npm install -D husky lint-staged
npx husky install
npm pkg set scripts.prepare="husky install"
npx husky add .husky/pre-commit "npx lint-staged"
```

**เพิ่มใน root `package.json`:**
```json
{
  "lint-staged": {
    "frontend/src/**/*.{ts,tsx}": ["cd frontend && npm run lint:fix", "cd frontend && npm run format"],
    "backend/src/**/*.ts": ["cd backend && npm run lint:fix", "cd backend && npm run format"]
  }
}
```
