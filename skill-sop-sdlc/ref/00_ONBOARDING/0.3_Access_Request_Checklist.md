## Security Reminders

### สิ่งที่ต้องทำ

- ✅ เปิดใช้ **2FA (Two-Factor Authentication)** ทุกระบบที่รองรับ
- ✅ ใช้ **Password Manager** (เช่น 1Password, Bitwarden)
- ✅ ใช้ **Password ที่แข็งแรง** (อย่างน้อย 12 ตัวอักษร)
- ✅ **ไม่แชร์ Credentials** กับใคร
- ✅ **Logout** เมื่อใช้เครื่องสาธารณะ

### สิ่งที่ห้ามทำ

- ❌ ห้าม Commit credentials ลง Git
- ❌ ห้ามเก็บ Password ใน Plain Text
- ❌ ห้ามแชร์ API Keys ผ่าน Chat
- ❌ ห้ามใช้ Personal Account สำหรับงาน Production
