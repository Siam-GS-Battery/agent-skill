# 4.6 Live Preview (environment-aware)

## วัตถุประสงค์

เป้าหมายสูงสุดคือเพื่อให้ผู้ใช้ที่ไม่ใช่ dev ได้ **เห็นและอนุมัติ (approve)** หน้าตาและพฤกติกรรมจริงของแอปพลิเคชัน (Review/Approval Gate) โดยไม่จำเป็นต้องสั่งรันหรือพึ่งพาเซิร์ฟเวอร์รันค้างไว้ในระบบ (Background Server) เนื่องจากสภาพแวดล้อมแซนด์บอกซ์ (Sandbox) จะยุติการทำงานของบริการเบื้องหลังทุกครั้ง

---

## 1. วิธีดำเนินการบนระบบ Sandbox

### A. การยืนยันความถูกต้องฝั่ง Logic (VERIFY)
- หลีกเลี่ยงการเปิดรันเซิร์ฟเวอร์ (backend/frontend) ทิ้งไว้แบบ background process
- ให้ทำการตรวจสอบความถูกต้องของระบบโดยใช้ **คำสั่งเชลล์เพียงคำสั่งเดียว (Single-run Command)** ที่สั่งรันฐานข้อมูล/API ชั่วคราว ทำการเรียกทดสอบ Health Endpoint (`/api/health`) รันสคริปต์จำลองเหตุการณ์ตาม Acceptance Criteria (เช่น Login -> Create -> Stock in/out -> Guard Checks) แล้วแสดงผลลัพธ์ในรูปแบบ JSON Log ทันที จากนั้นยุติโปรเซสทั้งหมด

### B. การจำลอง UI สำหรับ User (Interactive SIDEBAR Preview)
- เนื่องจากระบบแซนด์บอกซ์ปิดกั้นการติดต่อเครือข่ายภายนอก (network-isolated) และไม่รองรับการรันพอร์ตทิ้งไว้ ให้ใช้วิธี **สร้างหน้าเว็บจำลองแบบเสร็จสมบูรณ์ในไฟล์เดียว (Self-contained HTML Page)**
- เรียกใช้เครื่องมือ `create_artifact` เพื่อสร้างไฟล์ HTML หน้าเดียวที่ฝัง CSS/JS ในตัว และนำข้อมูล Seed Data มาจำลองใน Memory (in-memory mock data) เพื่อแสดงผลหน้าจอทั้งหมดตาม Acceptance Criteria
- หน้าเว็บจำลองนี้ต้องไม่เรียกใช้ API ไปยัง local backend แต่สามารถเชื่อมโยงข้อมูลจำลองหรือเรียกใช้งาน MCP Tools ผ่าน `window.cowork.callMcpTool` ได้หากจำเป็น

---

## 2. Preview Gate (✅ Checklist)

ต้องผ่านเงื่อนไขเพื่อผ่าน gate:
- [ ] Logic และ API ฝั่ง backend ผ่านการตรวจสอบผ่านสคริปต์แบบรันครั้งเดียว (Single-run Verification) โดยผลลัพธ์ JSON ใน Log ถูกต้องทั้งหมด
- [ ] หน้าจอจำลอง UI ในรูปแบบ HTML Artifact สามารถจำลองปุ่ม การคลิก และการทำงานตามเกณฑ์การทดสอบ UAT ได้อย่างสมบูรณ์
- [ ] การแสดงผลจำลองสถานะ loading / empty / error ของแต่ละหน้าจอครบถ้วน
- [ ] ผู้ใช้เห็นภาพการทำงานจริงของหน้าจอและอนุมัติ (approve) เรียบร้อย
- [ ] Pack code to be a container: runnable via the root `docker-compose.yml` container stack
